## Ubuntu启动及复测

请解压到新的独立目录，不覆盖唯一一份旧项目；首次使用新目录会创建初始数据库。若需保留历史测试数据，先单独备份旧 charging_platform.db，确认两端关闭后再处理数据库迁移。

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build -j2
ctest --test-dir build --output-on-failure
bash scripts/run-desktop.sh admin
```

另开终端，在同一项目目录：

```sh
bash scripts/run-desktop.sh user
```

再开第三个终端重复用户端启动命令，登录另一个手机号，测试同时在线、同桩预约、冻结、断线重连。两端操作后等待约5秒确认列表及统计更新。确认窗口最小尺寸下可滚动到所有内容，Shift+滚轮/水平滚动条可查看宽表格。

启动脚本不会安装输入法、不会改动用户配置，也不会打印腾讯Key。它只在已有输入法进程及对应Qt插件可用、且未设置QT_IM_MODULE时选择模块。若系统其他应用也不能输入中文，请在Ubuntu的语言/键盘设置中启用中文拼音；若系统应用正常而Qt应用不正常，检查与Qt版本匹配的输入法插件。Windows到Ubuntu复制粘贴依赖VMware Tools和客户机隔离选项；应用内右键粘贴无法替代虚拟机剪贴板共享。
